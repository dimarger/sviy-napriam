# Свій напрям

Український мінітест професійних інтересів для учнів та учениць 9 класу.

- 12 запитань із варіантами відповіді.
- Шість напрямів, приклади професій і практичні наступні кроки.
- Чесне відображення однакових балів, перегляд і зміна відповідей.
- Завантаження результату у TXT та повторне проходження.
- Адаптивний інтерфейс для телефонів і комп’ютерів, без реєстрації.

## GitHub Pages

Адреса після ввімкнення Pages: https://dimarger.github.io/sviy-napriam/

У [Settings → Pages](https://github.com/dimarger/sviy-napriam/settings/pages) оберіть:

1. Source: **Deploy from a branch**.
2. Branch: **main**, папка **/ (root)**.
3. Натисніть **Save** та дочекайтеся завершення публікації.

## Як працює сайт

Увесь застосунок міститься в `index.html`: компіляція та встановлення залежностей не потрібні. Файл можна також відкрити локально подвійним кліком. Шрифт Manrope завантажується з Google Fonts; без мережі використовується системний шрифт.

Кожна відповідь дає один бал одному напряму. Бали відображають інтереси, а не здібності або ймовірність успіху. Відповіді зберігаються лише у поточній вкладці (sessionStorage, якщо доступне).

Це авторський орієнтовний тест інтересів, а не стандартизована професійна психодіагностика. Актуальні умови вступу слід перевіряти у закладах освіти.
